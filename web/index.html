A reproducible integration case

A narrower path scope dropped the advanced docs.

The baseline searches all indexed FastAPI documentation. The candidate keeps only paths under tutorial/. Search still finds the WebSocket and application-lifespan sources, but the next recorded stage excludes them.

Every result in the report comes from an executed LangChain chain with BM25 retrieval. The sources, checksums, questions, configuration, and removal annotations are available to inspect.

The corpus is real. The eight questions and the filter change were authored for this controlled experiment. Document presence is measured; generated answers are not.

Run the experiment locally.

Clone the code and install the optional example dependencies. The pinned documents are included; the experiment makes no model or document-download requests. 

git clone https://github.com/Sampsonyu/retrieval-diff.git
cd retrieval-diff
python -m venv .venv
. .venv/bin/activate
python -m pip install -e . \
  -r examples/fastapi_docs/requirements.txt
python examples/fastapi_docs/run.py

Python 3.12+ for this pinned example. The core comparator supports Python 3.10+ and has no runtime dependencies.

Try your own retrieval change.

Record ranked results at the stages you want to inspect. Compare the exported snapshots locally and share the generated report with your reviewers. 

retrieval-diff compare baseline.json candidate.json \
  --k 5 --require-labels --html report.html

Only final context available? You can compare source changes, but a missing source's cause stays unknown.

Recording API and input contract ↗

Help test whether this is useful.

We are looking for early users who change retrieval filters, ranking, or context budgets. The most useful feedback is whether you could capture the stages and whether the report revealed anything you had missed.

Share trial feedback ↗

Know what the report can establish.

  • Labels check relevant source presence, not passage correctness or answer accuracy.
  • Stage disappearance is observed. Removal reasons come from your instrumented retriever.
  • Missing queries, changed labels, and different corpus fingerprints invalidate a comparison.
  • External adoption and production-scale performance remain unvalidated.
