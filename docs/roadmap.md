# Roadmap

## Implemented in the first version

- Version-1 snapshot validation and Python recording API.
- Comparable-run checks; per-query document recall and reciprocal rank.
- Last-observed-stage diagnosis with optional recorded removal reasons.
- Offline interactive HTML, JSON, Markdown, and CLI quality-gate exit codes.
- Reproducible synthetic BM25 example with offsetting improvement/regression.

## Next: demonstrate independent utility

- Test capture in one actual RAG application using a public or permissioned corpus.
- Publish installable source and an example report after reviewing the artifact.
- Gather integration friction and repeated-use feedback from English-speaking users.
- Add one requested integration rather than claiming support for every framework.

## Later, conditional on demand

- Passage-level evidence anchors and source revision checks.
- Replayable retrieval configuration experiments.
- Representative performance tests and streaming for large snapshots.
- A packaged GitHub Action if the plain CLI workflow becomes cumbersome.

Success is a useful debugging workflow with repeat users and verifiable findings.
Repository popularity is measured separately. This is not a promise of adoption
or an unattended operating schedule.
